# Painel Decap CMS

O painel fica em `/admin/` depois que o site for publicado.

Antes de usar:

1. Abra `admin/config.yml`.
2. Troque `SEU_USUARIO/site-anthony-colares` pelo caminho real do repositório.
3. Configure a autenticação GitHub/OAuth proxy escolhida para o projeto.

O Decap salva alterações como commits no repositório. As imagens são enviadas para `imagens/uploads`.
